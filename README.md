# generazione-contenuti-GPT-SOCIAL

Repository di ricerca e sperimentazione per un workflow di contenuti social professionali assistiti da AI.

**Stato:** esplorativo; nessun prodotto definitivo approvato.

## Obiettivo
Dal brief ai concept alternativi, con approvazione umana dell'idea, generazione di asset, revisione e consegna di immagini statiche competitive per social. Per ora video, pubblicazione automatica e analytics avanzate sono fuori ambito.
