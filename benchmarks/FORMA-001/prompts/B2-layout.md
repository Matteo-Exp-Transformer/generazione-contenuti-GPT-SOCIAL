# Prompt B2 — Layout separato per Codex

Agisci come senior graphic designer ed editorial layout engineer. Progetta un layout Instagram professionale, riproducibile e modificabile utilizzando **solo asset fotografici approvati**.

Canvas finale: 1080 × 1350 px, sRGB. Brand: FORMA. Concept: INTERSEZIONI.

**Testi esatti:**
- FORMA
- DESIGN NOTES / 001
- La forma della luce
- Materiali, volumi e ombre: il linguaggio invisibile degli interni.
- INTERIOR STUDIES

**Vincoli:** griglia modulare 12 colonne; margini iniziali indicativi 64 px; fotografia principale asimmetrica; secondo riquadro preferibilmente ritagliato dalla stessa fotografia; gerarchia tipografica professionale; palette crema/terracotta/marrone; testi esatti e modificabili; livelli indipendenti; nessuna sovrapposizione accidentale; nessun elemento fuori canvas.

Preferire composizione riproducibile con HTML/CSS/SVG o strumenti equivalenti già disponibili, senza dipendenze superflue.

**Output futuro:** sorgente modificabile, PNG finale, metadati risorse, breve report QA.

**Prima di implementare:** verificare gli strumenti e presentare il piano. Non installare, modificare repository, creare file o generare immagini senza autorizzazione esplicita.
